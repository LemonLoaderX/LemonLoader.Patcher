- Select Android (default) or Bionic runtime releases with `--runtime` or the GUI
  Runtime selector. Download caches are separated by variant.
- Support Loader Android Preview 5 and its leaner release metadata. The DEX
  digest comes from validated release files and is written into the final APK
  payload after promotion to `classesN.dex`.
- Continue accepting older releases and rejecting incorrect legacy DEX hashes.
- Reuse verified file digests instead of repeatedly hashing release contents.
- Update Bionic APK verification and consolidate publishing path checks.

Windows x64 and Linux x64 packages contain CLI, GUI, and the maintained
Il2CppInterop generator. The desktop .NET 10 runtime is required.

Upgrade Patcher before using Loader `v0.7.3-android.5`. To switch an already
patched game's runtime, patch its original APK and use a same-signer replacement
installation. Do not uninstall or clear application data.
