Patcher **2.1.0** accepts the minimal Release manifest format **3** used by
[Loader v0.7.4-android.3](https://github.com/LemonLoaderX/LemonLoader/releases/tag/v0.7.4-android.3),
and preserves format-2 validation for existing layout-9 archives. Upgrade Patcher
before preparing a game with the new Loader archives.

The CLI/Core request interfaces and separate CLI/GUI archive layout remain
compatible with 2.0.0. Windows and Linux distributions still require .NET 10.

Default seed-only deployment now omits an empty policy list. File hashes, ZIP
safety, native-library collision checks and runtime completeness validation remain
required. See the [workflow and compatibility guide](https://github.com/LemonLoaderX/LemonLoader.Patcher/blob/v2.1.0/docs/WORKFLOW.md).

Updating Patcher does not resolve Loader's MuMu/native-bridge near-hook limitation;
the [Loader release notes](https://github.com/LemonLoaderX/LemonLoader/releases/tag/v0.7.4-android.3)
describe that boundary.
