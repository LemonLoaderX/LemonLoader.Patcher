# Security policy

Report vulnerabilities through GitHub's private vulnerability reporting for
`LemonLoaderX/LemonLoader.Patcher`. Do not publish proof-of-concept APKs or
signing credentials in an issue.

Reports should include the affected revision, input type, expected validation,
actual result, and a minimized synthetic fixture where possible. Remove game
content, account information, device identifiers, keystores, passwords, and
tokens from all attachments.

The current release line receives security fixes. Already-patched APK migration
and historical development builds are not supported.
